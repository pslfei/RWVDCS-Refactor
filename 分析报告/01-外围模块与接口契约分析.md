## 1. TDK.Core.DAL — 工程数据访问层

### 1.1 ORM 与连接方式

- **ORM**：NHibernate 2.x，映射文件 `*.hbm.xml` 通过程序集批量加载（`D:\项目\睿渥\RWVDCS\TDK.Core.DAL\hibernate.cfg.xml` 第 31–33 行）。
- **默认方言/驱动**：`SybaseDialect` + `OleDbDriver`，实际用于 **Access mdb**（`SessionHelper` 将 SybaseDialect 映射为 `DatabaseTypes.Access`，见 `D:\项目\睿渥\RWVDCS\TDK.Core.DAL\Utility\SessionHelper.cs` 第 97–99、145–148 行）。
- **连接字符串形态**：
  - 模板：`Provider=Microsoft.Jet.OLEDB.4.0; Data Source={mdb路径}`（`hibernate.cfg.xml` 第 23 行）
  - 运行时由 `SessionHelper.InitializeSessionFactory(DatabaseTypes dbType, string connString)` 注入（第 124–167 行）
  - Simulator 启动时调用 `m_dcs.SetDataBaseConenctString(...)` 设置工程库路径（`D:\项目\睿渥\RWVDCS\Simulator\ConsoleForm.cs` 第 357–361 行）
- **也支持 MySQL5**（方言 `MySQL5Dialect` + `MySqlDataDriver`，第 101–104、149–151 行），但仿真站默认走 Access。
- **CRUD 层**：`D:\项目\睿渥\RWVDCS\TDK.Core.DAL\CRUD\` 下按表提供 Query/SaveUpdate/Delete 类（如 `Cfg_VarSystem_Query.cs`）。

### 2.3 写入策略（队列 + 四线程）

```
AddAlarm/AddOpev/AddPoint/AddSoe → Queue<T>
  → 4 个后台线程 trdAlarmTask/trdOpevTask/trdPointTask/trdSoeTask
  → OleDbCommand.ExecuteNonQuery (StoredProcedure)
```

关键参数（`Hist.cs`）：

| 参数 | 默认值 | 行号 |
|---|---|---|
| MaxDbRow | 10000 | 27, 129 |
| ChkDbTime | 24h (ms) | 28, 121 |
| CacheHight | 10000（四队列总和上限） | 41, 183 |
| 队列加速阈值 | Alarm/Opev=20, Point/Soe=50 | 36–39 |
| 线程休眠 | 默认 1ms | 48, 143–171 |

**轮转/保留策略**（`tmrDB_Elapsed`，第 866–983 行）：
1. 任一张表行数 > MaxDbRow → 暂停写入线程
2. 刷完 TimeOA ≤ `_offTimeOA` 的旧数据
3. 备份 `History.mdb` 到 `HistBakDB\{minTOA}-{maxTOA}.mdb`
4. 用 `template.mdb` 重置当前库

### 2.4 查询路径

- **GUI 查询**：`D:\项目\睿渥\RWVDCS\History\QueryForm.cs`
  - 读视图存储过程：`Alarm_View`、`Opev_View`、`Point_View`、`Soe_View`（第 98–116 行）
  - 点元数据关联：`Configure.mdb` 的 `Cfg_VarSystem`（第 22–25、246–249 行）
- **Simulator 集成**：仅使用 `QueryForm`，**未实例化 `Hist` 写入服务**
  - `ConsoleForm.cs` 第 60 行：`private History.QueryForm m_dlg_hist`
  - 全库搜索 `new Hist(` / `Hist.`：**仅在 `Hist.cs` 自身出现**，写入服务当前处于**未接线**状态

### 2.5 Remoting 历史 API（声明但未实现）

`ICommunication` 定义了 `GetRecordsHistoryAlarm/Point/OperationRecord` 等（`PS.Comm Conponent\PS.Comm\ICommunication.cs` 第 382–525 行），但 `RemotingObj` 中对应方法**全部 return null/false**（`RemotingObj.cs` 第 350–593、928–941 行）。

### 2.6 当前局限

1. **Jet OLEDB 4.0**：仅 Windows，mdb 2GB 上限，并发差
2. **Hist 写入服务未接入主流程**：仅有 QueryForm 读库能力
3. **Remoting 历史查询接口空实现**
4. **值全为 string 存储**（Char 参数），无类型化列
5. **Thread.Abort** 停止线程（第 485–488 行），.NET Core 不可用
6. **Opev 写入有重复 dequeue 兜底**（第 687–701 行），说明曾遇 Access 并发问题

## 6. OPC UA 实现程度

### 6.1 Remoting2OPC 网关（项目内自研桥接）

路径：`D:\项目\睿渥\RWVDCS\Remoting2OPC\`

**工作流程**（`Form1.cs`）：
1. `ClientObj` 连接 VDCS Remoting（第 34–76 行）
2. 遍历 DPU→Block→Output 管脚 + 系统点，收集 `OpcNames`/`OpcTypes`（第 77–128 行）
3. `OpcServerApplication(OpcNames, OpcTypes)` 创建 LibUA 节点（第 137 行）
4. LibUA Server 监听 **7718**（第 139 行）
5. 重新连接并订阅，`OnVDCSDataChange` → `opcServerApplication.UpdateValue`（第 164–167 行）

**节点暴露**（`OpcServerApplication.cs` 第 51–102 行）：
- 根节点 `Items`（NodeId namespace 2）
- 每个点名一个 `NodeVariable`
- 类型映射：**仅 LA→Float、LD→Boolean**，其他类型未映射（第 79–90 行）
- 访问级别：CurrentWrite | HistoryRead

**历史数据**：`HandleHistoryReadRequest` 返回**合成正弦测试数据**，非真实历史（第 269–308 行）。

**事件**：`GenerateSampleAlarmEvent` 生成样例报警，默认不推送（第 487 行注释掉）。

### 6.2 OpcUaHelper（第三方 OPC UA 客户端库）

路径：`D:\项目\睿渥\RWVDCS\OpcUaHelper\OpcUaClient.cs`

- 基于 OPC Foundation `Opc.Ua.Client`
