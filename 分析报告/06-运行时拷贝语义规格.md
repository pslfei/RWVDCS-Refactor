# 06 运行时拷贝语义规格（Dpu/Command/Wire 六阶段数据流精读）

> 来源：老系统源码精读（`D:\项目\睿渥\RWVDCS`），2026-07-06。
> 用途：新系统 `DpuRuntime`/`BlockCommand` 执行流水线的对齐依据。

## 摘要

**Joint Wire** 每周期只拷贝 **buffer/标量值**（`TryRawCopy` 1/2/4/8 字节，或 `PinCalculationCache[i]` 读写 buffer；`CopyTo` 按 `VariableAddress.Length` 整段字节拷贝）。**不拷贝** quality、isforced、forcevalue、istrace、isalarm。

**强制**：`Dcs.ForcePin` → `SetPinForce` 写入 `_forceState`；每周期在 **fc.Implement 之后** 的 `_outputPinSync` 阶段重设 `IsForced=1`、`forcevalue`，并把 `v.Value` 写回 RTD buffer；取消强制时恢复 `_preForceValues`。不写 Point（Point 由 OUT Wire / `SyncOutputPinsToTargetPoints` 获得值）。

**Quality**：Wire / Sync 表 **不传播**；由功能块 Run 内显式赋值（如 PID：`OUT.Quality = E.Quality`）。

## 1. 周期总流程伪代码

### 1.1 DPU 级（`Dpu.Implement` 879–1049）

```
loop forever:
  if state in {Stop, Pause}: return

  switch state:
    Step:
      state = Pause
      for cmd in commands: cmd.Execute()
      cycleCount++; rtd.CycleCount = cycleCount
      break   // 无 CheckIn、无 DrainIomap、无 Sleep

    Run:
      wait until canCheckIn        // Dcs.CheckIn 屏障
      StartCycle()
      dcs.CheckIn(dpu.name)        // 全部 DPU 到齐 → CheckInOpen → CanCheckIn=true

      rtd.DrainIomapPendingWrites()   // IOMAP 队列写入 buffer（959–963）

      for cmd in commands:
        cmd.Execute()

      cycleCount++
      rtd.CycleCount = cycleCount
      rtd.TriggerRefresh()

      cycleTime = EndCycle()
      sleep max(0, cycle_ms - cycleTime - synWait)

      break   // 每轮只跑一个周期
```

- **`Dpu.Cycle`**（204–215）：对外 **秒**（`cycle/1000`）；内部 `cycle` 为 **毫秒** uint，默认 200ms。
- **`Dpu.CycleCount`** / **`rtd.CycleCount`**：`uint`，每周期 +1。
- **Step vs Run**：Step 无 IOMAP 安全点、无 CheckIn、无 TriggerRefresh（919–921）、无周期 Sleep。

### 1.2 CheckIn 协议（`Dcs.cs` 5441–5479）

```
CheckIn(dpuname):
  lock:
    currentCheckInCount++
    dpu.CanCheckIn = false
    if currentCheckInCount == GetRunningDpuCount():   // 实际为 m_dpuList.Count
      CheckInOpen()   // 所有 DPU CanCheckIn=true
      currentCheckInCount = 0
```

Run 模式 DPU 在 `while(!canCheckIn) Sleep(1)` 处等待全部 DPU 签到。

### 1.3 Command 级六阶段（`FirstRun` 1129–1336 / `Execute` 1342–1577）

```
iomapActive = IomapOwnership.AnyOwned

// 阶段1: IN Wire Inner
for w in referenceWires: if IN|IO: w.Transmit(rtd, Inner)
for w in jointWires:     if IN|IO: w.Transmit(rtd, Inner)

// 阶段2: 源 Point → 本块输入 Pin buffer + live fc
SyncInputPinsFromSourcePoints()   // _inputPointSync

// 阶段3: RTD buffer → live fc（无 Point 连接的 Pin）
for entry in _inputPinSync:
  if TryEqualsBufferedFast(fsid, pin.Value): continue
  val = TryGetVariableFast / rtd[sid, bufferOffset]
  pin.Value = val; writer(fc, pin)

// 阶段4: 功能块
FirstRun: fc.FirstRun(this)
Execute:  fc.Implement(this)   // → Run(cmd) if runable

// 阶段5: live fc → RTD buffer（含强制）
for entry in _outputPinSync:
  if iomapActive && IsOutputPinOwnedByIomap: continue
  if forced: IsForced=1, forcevalue, write v.Value → RTD buffer; continue
  if !forced && was forced: clear IsForced, restore _preForceValues
  if Execute && TryEqualsBufferedFast: skip write
  else: write v.Value → RTD buffer

// 阶段6a: OUT Wire Outer
for w in jointWires/referenceWires: if OUT|IO:
  if iomapActive && IsWireTargetOwnedByIomap: skip
  w.Transmit(rtd, Outer)

// 阶段6b: live fc 输出 → 目标 Point（最后写入）
SyncOutputPinsToTargetPoints(iomapActive)
```

## 2. 六阶段字段级拷贝表

| 阶段 | 源 | 目标 | 拷贝字段 | 粒度 | quality/强制/告警 |
|------|-----|------|----------|------|-------------------|
| 1 IN Wire | Point buffer / 上游 Pin buffer | 本块 Pin buffer | **仅 value/buffer** | 见 Wire 节 | **否** |
| 2 SyncInputFromPoint | 源 Point.buffer 或 Point.Value | 本 Pin buffer + live fc `IValuable.Value` | **value**；`reversed` 时逻辑取反 | 标量/整 buffer | **否**；IOMAP 输入回盖 HMI 值（2736–2756） |
| 3 _inputPinSync | RTD pin buffer | live fc `Value` | **buffer→Value** | 基础类型 fast path | **否** |
| 4 fc.Run | — | Pin 字段 | 块内读写 live fc | 块逻辑自定 | 块内可设 Quality |
| 5 _outputPinSync | live fc / `_forceState` | RTD pin buffer + pin 强制字段 | **Value→buffer**；强制时 **IsForced, forcevalue** | buffer FSID | 强制不写 quality |
| 6a OUT Wire | Pin buffer | Point buffer | **仅 value/buffer** | 同 Wire | **否** |
| 6b SyncOutputToPoint | live fc Pin.Value | Point buffer 或 `Point.Value` | **Value**；可 reverse | 标量/整对象写回 | **否**；IOMAP 输出回盖（3050–3071） |

**不随周期拷贝的 Pin 元数据**：quality、isforced（非强制路径）、forcevalue（非强制路径）、istrace、isalarm — 在 Command 六阶段中 **均未同步**。

## 3. RebuildPinSyncTables 构建规则（2330–2455）

| PinType | `_inputPointSync` | `_inputPinSync` | `_outputPinSync` | `_outputPointSync` |
|---------|-------------------|-----------------|------------------|-------------------|
| Input + 有 PointName | ✓ | ✗（F1 去重） | ✓ | — |
| Input + 无 PointName | ✗ | ✓ | ✓ | — |
| Output/IO + Wire | — | ✗ | ✓ | ✓（每条 OUT/IO Wire） |
| Internal/Constant | ✗ | ✗ | ✗ | ✗ |
| FunctionCode 嵌套块 | ✗ | ✗ | ✗ | ✗ |

同步委托：`reader/writer` = `FieldInfo` 编译 delegate；拷贝 **`IValuable.Value`** 或 RTD `[sid, bufferOffset]`，非整 struct 反射克隆（值类型 Pin 每周期 reader+writer）。

> **重要旁注（已实证）**：LoadFile 反序列化路径下，本方法只能从**已恢复的 Wire 对象**反查
> PointName——凡是无 Wire、纯靠 PinDetails 同步表连接的块，加载后输入/输出点绑定
> 永久丢失（`FindWireByPinName` 返回 null → `_inputPointSync`/`_outputPointSync` 空）。
> 这是「wrk 迁移续跑对账 44 处差异」的根因，详见 `docs/工况快照与wrk迁移.md` §3.4。

## 4. TryEqualsBufferedFast（1185/1401/1505–1514；`PointManage` 3877–3954）

- **比较对象**：live Pin 的 **boxed Value** vs RTD buffer **原始字节**（`EqualsValueFastNoLock`）。
- **支持类型**：float/int/bool/byte/short/long 等定宽基础类型；LA/LD 等复杂 struct **返回 false**，走完整同步。
- **跳过时副作用**：不读 RTD、不写 buffer、不 `writer(fc,pin)` — live fc 保持上周期值（输入）或 RTD 保持旧 buffer（输出 Execute 路径）。

## 5. 强制 / IOMAP 规则

### 5.1 强制（529–554, 1469–1501）

| 时机 | 动作 |
|------|------|
| `SetPinForce(true)` | 首次保存 `_preForceValues[pin]=v.Value`；`_forceState=(true, forceValue)` |
| 每周期 `_outputPinSync` | `IsForced=1`；`SetMemberValue(forceValue,"forcevalue")`；`v.Value` → RTD buffer |
| `SetPinForce(false)` | `_forceState=(false,null)`；下周期清除 `IsForced`，恢复 `_preForceValues` |
| Point | **不直接写**；依赖阶段 6 |

### 5.2 IOMAP 守卫

| 守卫 | 跳过 |
|------|------|
| `IsOutputPinOwnedByIomap` | `_outputPinSync` 回写 pin buffer |
| `IsWireTargetOwnedByIomap` | OUT `Wire.Transmit` |
| `SyncOutputPinsToTargetPoints` | 正常写；IOMAP 占用时用 HMI 值 **回盖** point buffer |
| `SyncInputPinsFromSourcePoints` | IOMAP 占用输入：先把 HMI 值写入源 buffer，再读出 |

## 6. Wire.Transmit 决策表（217–629）

### 6.1 首次初始化

| attribute | 动作 |
|-----------|------|
| **Reference** | `ConnectPointToPin(pointAddr,pinAddr)` 写 pin.pinner 指针；缓存 `point`/`pin` 对象 |
| **BlockReference** | `fc[PinName]=RTD[PointName]` 一次性引用赋值 |
| **Joint** | 建 `inPutPinCache`(pin FSID) + `outPutPinCache`(point FSID)；中间 Point 可能 `skipCache→CopyTo` |

### 6.2 方向 × WireType 过滤

| Direction | 跳过 |
|-----------|------|
| Inner | `type==OUT` → return true |
| Outer | `type==IN` → return true |

### 6.3 Joint 拷贝语义（核心）

**Inner（Point→Pin）**：`outPutPinCache[outIndex]` → `inPutPinCache[inIndex]`
**Outer（Pin→Point）**：`inPutPinCache[inIndex]` → `outPutPinCache[outIndex]`

- **TryRawCopy**：同源同宽定宽类型，拷贝 **RawByteLength** 字节（1/2/4/8），**仅 buffer 内存**。
- **PinCalculationCache[i]**：标量读写 buffer；LA/LD/LP/LP32 读整 struct、改 `[i]`、写回整 struct — 仍 **不含 quality 字段**（quality 在 struct 其它偏移，indexer 不触及则不变；存疑：LP 位操作只改 buffer 字）。
- **CopyTo fallback**：`memoryManage.Copy(..., Length, reversed)` — **Length 字节** 块拷贝；`reversed=true` 逐字节 `~`（382–410）。

### 6.4 取反 `reversed`

| 类型 | 处理 |
|------|------|
| bool | `!value` |
| float | `"0"→true`, `"1"→false`（ToString 比较，存疑语义） |
| 其它值类型 | Marshal 序列化后 **逐字节按位取反** |
| `ReversePointValue`（Sync 路径） | bool 取反；float 0↔1；其它 `~Convert.ToInt64` |

### 6.5 inIndex / outIndex

Wire 字段默认 **-1**，代码库 **无赋值**（199–200）。
- 非 LP Pin：`Pin[i]` / `Get/Set` → 整 **buffer** 字段。
- LP（`Point<short>` 派生）：`i<0` 时 get 返回 **default(T2)**，set **no-op**（184–227）— **存疑**：LP 位接线在当前组态下是否走 Wire 路径。

### 6.6 Reference 与 ConnectPointToPin（2950–3048）

- 在 pin 内存 `Pin.Offset` 写入 **Point 物理地址指针**（引用类型 +4 跳过 syncblk）。
- 运行时 Transmit 仍通过 `point[outIndex]` / `pin.Set(inIndex,...)` 做 **值拷贝**到 pin buffer（非零拷贝别名语义；对重构：需每周期显式拷贝 value）。

## 7. FirstRun vs Execute 差异

| 项 | FirstRun | Execute |
|----|----------|---------|
| FC 调用 | `fc.FirstRun(this)` | `fc.Implement(this)` |
| IN Wire 失败 | **Remove** wire | 保留，下周期重试 |
| OUT 写优化 | 无 `TryEqualsBufferedFast` skip | 输入/输出均有 skip |
| `_forceState` | 每 entry TryGetValue | `forceActive` 预判 |
| 异常 | Transmit 失败 remove；OUT catch 保留 wire | Implement/OUT 吞异常 |

**PostDeserializeSetup**（1743–1780）：`PrepareAfterDeserialize` = `RebuildPinSyncTables` + `ReconnectWires(Inner only)`；**不** FirstRun、**不** Sync 表执行；末尾 `TriggerRefresh`。

## 8. Function 基类 API（`Function.cs` 要点）

```csharp
[VariableClass(Block)] [FCName("AbstractFunction")]
abstract class Function {
  [PinType(Constant)] string FcName, FcCode;
  [PinType(Internal)] protected bool runable;
  private ICommand command;
  public virtual ICommand Command { get; set; }   // 无额外副作用
  public bool Runable { get; set; }
  public string Name { get; }                     // 来自 FCNameAttribute
  protected abstract void Run(ICommand cmd);
  public virtual void FirstRun(ICommand cmd) { }
  public void Implement(ICommand cmd) {
    if (runable) Run(cmd);   // 异常吞掉
  }
  // virtual SetMemberValue/GetMemberValue：runable, FcName, FcCode
}
```

**PinType**（`Enum.cs` 252–282）：Input/Output/IO/Constant/Internal/Cascaded/None
**WireTypes**：Invalid/IN/OUT/IO
**VariableClass**：Point/Tag/Block/Macro

## 10. 三块抽查

- **PID**（15, 131）：`cmd.Dpu.Cycle` 作积分步长；`OUT.Quality = E.Quality` / 跟踪用 `TR.Quality`。
- **TIMER**（17, 214–232）：`cmd.Dpu.Cycle` 作 dt；按 `QualityT` 配置传播 X→OUT/TRun Quality。
- **DELAY**（15, 79–103）：`cmd.Dpu.Cycle` 算滞后周期 d；溢出/QualityT 控制 OUT.Quality。
