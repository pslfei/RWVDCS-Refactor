# 05 工程装载语义规格（LoadDB 精读）

> 来源：老系统源码精读（`D:\项目\睿渥\RWVDCS`），2026-07-06。
> 用途：新系统 `MdbEngineeringReader`/`RuntimeBuilder` 的对齐依据；对账差异排查手册。

## 关键发现摘要

**执行顺序**由 Access 无 `ORDER BY` 的物理返回序决定（块/管脚/点均如此）；`InitCommand` 对各 DPU 用 `Task` 并行且**未 `WaitAll`**，与 `FirstRun()` 存在竞态（存疑）。**宏块不展开**：不读 `Micro_*`，`MacroID` 未过滤，`FunctionName` 直接作 FCName。点名=`Cfg_VarSystem.Name` 原样（无 DPU 前缀）；块名=`Cld_FCBlock.AlgName`（`文档ID$SheetID$符号名`）；中间点=`源AlgName.管脚名`，类型固定 LA。

### 1.1 并行性与确定性

- **InitPoint**：严格按 `GetControllers()` 返回顺序、单线程串行（`Dcs.cs:1512-1541`）。
- **Prefetch**：5 表并行读，仅影响性能，分组后每桶内顺序=全表扫描顺序（`DcsOperation.cs:129-145`）。
- **InitCommand**：多 DPU 并行；单 DPU 内 `lock(this)`（`Dpu.cs:1409`）。**Task 未等待即调用 `FirstRun()`**（`Dcs.cs:1603`）——复刻时必须标注为存疑竞态。
  （新系统对策：`LegacyRunner.DeterministicLoad` 串行重放；新系统装配天然确定。）
- **Command 创建顺序**：`blockNamesToFCNames` 为 `Dictionary`，插入序=块遍历序；枚举顺序在 .NET 4.7.2 下稳定但未文档化（存疑）。

## 2. 等价 SQL 与遍历顺序

### 2.1 数据库连接


### 2.5 每 DPU — 块与管脚（Open）

## 3. 点装载规格

### 3.1 数据源

- 表：`Cfg_VarSystem`
- 过滤：`Prj_Controller_ID = controllerID`
- 点名：`SysPointName = var.Name` **原样**，不加 DPU/控制器前缀（`Operation.cs:187-188`）
- `IOMapName` 列：**装载未使用**

### 3.2 类型映射

| `DataType` 列 | RTD `TypeName` | 是否注册 | 备注 |
|---------------|----------------|----------|------|
| `LA` | `LA` | 是 | 解析 DefaultValue/Scale |
| `LD` | `LD` | 是 | bool 默认 |
| `LP` | `LP` | 是 | 无 DB 初值写入 |
| `LP32` | `LP32` | 是 | 无 DB 初值写入 |
| `int`/`float`/其他 | — | **跳过** | switch 无分支（`Operation.cs:217-231`） |

### 3.3 默认值解析规则

| 列 | 适用类型 | 解析 | 写入 RTD |
|----|----------|------|----------|
| `DefaultValue` | LA | 非空→`float.Parse` | `buffer`（`Dpu.cs:1447-1450`） |
| `DefaultValue` | LD | `"1"`→`true`；否则 `"false"`→`bool.Parse` | 仅 `buffer` |
| `DefaultValue` | LA/LD | 空串 | 保持类型零值（LA=0, LD=false） |
| `MinimumScale` | LA | 非空→`float.Parse` | `[TypeName,"MinValue"]`（`Dpu.cs:1467-1471`） |
| `MaximunScale` | LA | 非空→`float.Parse` | `[TypeName,"MaxValue"]` |
| `ForceValue` | 全部 | 非空→`float.Parse` | **未写入 RTD**（注释掉 `Dpu.cs:1478-1482`） |
| 报警限值列 | — | 代码已注释 | 不装载 |

**quality**：`RTD.New` 后由 `typeManage.WiseCopy` 填类型模板（通常 `QualityTypes.Good`）；InitPoint **不单独写 quality**（`PointManage.cs:554-556`）。

**ForceValue/IsForced**：解析了但未应用到 RTD（存疑：LD 构造时 Force 参数全 false，`Operation.cs:223`）。

### 3.4 伪代码

```
FOR var IN Cfg_VarSystem WHERE Prj_Controller_ID = ctrlId   -- 扫描序
  name = var.Name
  dt = var.DataType
  PARSE defaults per rules above
  SWITCH dt:
    LA   -> PointDetails<float>(name, "LA", fDef, Max, Min, Force, Unit, Desc)
    LD   -> PointDetails<bool>(name, "LD", bDef, false×3, Unit, Desc)
    LP   -> PointDetails<short>(name, "LP", Unit, Desc)
    LP32 -> PointDetails<long>(name, "LP32", Unit, Desc)
  points.Add; pointDict[name] = details

FOR details IN points:
  sid = rtd.New(details.PointName, details.TypeName, Point)
  rtd[sid, buffer] = details.DefaultValue
  IF TypeName=="LA": write MinValue/MaxValue offsets
  dcs.RegisterPointMeta(name, Desc, Unit, Min.ToString(), Max.ToString())
```

(`Operation.cs:159-314`；`Dpu.cs:1429-1485`)

## 4. 块装载规格

### 4.1 命名

| 概念 | 来源 | 格式 |
|------|------|------|
| 块名 (Command.Name) | `Cld_FCBlock.AlgName` | `{Prj_Document_ID}${Prj_Sheet_ID}${符号名}`，例 `2001$202$HAI24` |
| FCName | `Cld_FCBlock.FunctionName` | 与 `FCManufactory.Types` 键匹配 |
| 映射 | `blockNamesToFCNames[AlgName]=FunctionName` | `Operation.cs:349-350,580` |

### 4.2 过滤（跳过不建 Command）

```csharp
IF FunctionName IS NULL OR empty -> continue
IF FunctionName IN ('H_PI','H_RTD','H_TC','H_ELC') -> continue
IF FunctionName == 'APSM' -> 跳过 Command 与中间点（Dpu.cs:1501,1595）
```

(`Operation.cs:357-361`；`Dpu.cs:1497-1598`)

### 4.3 宏块

- `MacroID` 字段存在但**当前不过滤**（`DcsOperation.cs:291` 注释）。
- **不读** `Micro_FCMaster`/`Micro_FCDetail`。
- 宏实例：`FunctionName` 存宏名，运行库按**单个 RW 功能块**实例化，**不展开**子块（`Cld_FCBlock.cs:32-33,47`）。

### 4.4 块遍历伪代码

```
FOR block IN blocks   -- Open 后列表，无 Sequence 排序
  FCName = block.FunctionName; AlgName = block.AlgName
  SKIP per filters above
  pins = {}
  PROCESS inputs, outputs, parameters -> fcDetails[AlgName]=pins
  blockNamesToFCNames[AlgName] = FCName
  pins["Description"] = PinDetails<string>("", block.Description)
opened = true
```

(`Operation.cs:340-600`)

## 5. 管脚/参数/接线规格

### 5.1 Input/Output 管脚（Cld_FCInput / Cld_FCOutput）

| 列 | 作用 |
|----|------|
| `PinName` | 字典键；与 FC C# 字段名匹配（Command 内大小写不敏感，`Command.cs:1768-1775`） |
| `PointName` | 非空→建 Wire；作为 PinDetails.PointName |
| `InitialValue` | 仅当 `PointName` 空时使用 |
| `Point` | **未使用** |
| `Visible` | **未使用** |
| `Negate` | **未使用**；取反靠 `PointName` 中 `~` |

**InitialValue 解析**（`PointName` 为空时，`Operation.cs:395-408`）：
- `"true"`→1，`"false"`→0，否则 `float.TryParse`
- 空→`PinDetails<float>()` 无默认值

**PointName 非空时**（`Operation.cs:376-391`）：
- Wire 目标点名 = `PointName`（经 `PinDetails` 构造器去 `~`）
- Pin buffer 初值 = `pointDict[PointName].DefaultValue`→float；失败→0

**取反 `~` 规则**（`Function.cs:343-361`）：
- 含 `,` 的多点名：**不**在 AnalysePointName 处理 `~`（Output 在 Command 内逐段处理，`Command.cs:1983-1991`）
- 单点名：含 `~`→`Reverse=true`，去掉所有 `~`

### 5.2 Constant 管脚（Cld_FCParameter）

- 键：`param.Name`；值：`param.PValue`
- `PValue.Contains(":=")` → `PinDetails<string>("", PValue)`（HollySys 内部参数，`Operation.cs:498-501`）
- 否则查 `Meta_FCDetail`（`FunctionCodeMasterManager.GetDetail(FCName, ConstantPinName)`）：
  - `DataType.StartsWith("string*")` → 字符串 Pin
  - 含 `,` 且 array 类型 → `PinDetails<float[]>`
  - 否则数值 Pin（true/false/ float.TryParse）
- **Meta 未命中**：仅记入 debug dict，仍尝试 float 路径（`Operation.cs:524-535`）
- **存疑**：`DataType` 变量跨管脚复用，Meta 未命中时可能沿用上一管脚类型（"粘性默认"来源，
  已实证：行序对齐后该语义自动一致）

### 5.3 Command 构造时的 Wire 决策

**LoadDB 主路径**：5 参构造器 `Command(Name, FCName, Rtd, Dpu, Operation)`（`Command.cs:1729`），**不调用** `AddWire()`，直接 `new Wire(...)` 加入 `referenceWires`/`jointWires`。

| 条件 | WireAttributes | WireTypes |
|------|----------------|-----------|
| 字段类型 `FunctionCode.*` | `BlockReference` | IN/OUT/IO 按 PinType |
| 值类型字段 | `Joint` | 同上 |
| 引用类型字段 | `Reference` | 同上 |

(`Command.cs:301-307`)

| PinType | 建 Wire 条件 | Pin 地址 |
|---------|-------------|----------|
| Input | `PointName` 非空 | `IsPinPointName`→buffer 偏移；否则 pinner 偏移 |
| Output | 非空；可逗号分隔多个点名 | 同上；`~` 逐段处理 |
| IO | 非空 | 同上 |
| Constant | 无 Wire | 写 pinner/buffer + 反射 SetValue |

**IsPinPointName**（`Command.cs:2304-2316`）：
```
CONTAINS('.') AND NOT StartsWith('!') AND NOT StartsWith('!FRED1R/!FRED1S') AND NOT EndsWith('.0')
```

**IRef/ORef/跨图**：无单独解析；跨块连接体现为 `PointName`=`{源AlgName}.{源PinName}`，由中间点机制处理（见 §6）。

**Cld_Signal**：不参与 Wire 构建。

## 6. 中间点注册规格

触发：`InitCommand` 中，在创建 Command **之前**（`Dpu.cs:1493-1588`）。

```
registered = HashSet
FOR (blockName, fcName) IN BlockNamesToFCNames:
  IF fcName=="APSM" -> SKIP
  FOR (pinName, pd) IN initOperation[blockName]:
    IF pd.PointName empty OR NOT IsPinPointName(pd.PointName) -> SKIP
    fullName = pd.PointName
    srcBlock = fullName.Substring(0, LastIndexOf('.'))
    srcPin = fullName.Substring(dot+1)
    IF srcBlock NOT IN BlockNamesToFCNames -> THROW
    IF fullName NOT IN registered:
      rtd.New(fullName, "LA", Point)   -- 固定 LA
      registered.Add(fullName)
    APPEND fullName TO srcBlock[srcPin].PointName (comma join)
```

- 类型：**LA**，初值由 RTD 类型模板决定，**不**写 Cfg 默认
- 格式：`{源块AlgName}.{源管脚PinName}`，例 `2004$604$ABS77.OUT`
- 非中间点：`IsPinPointName==false` 的普通点名直接 Wire 到 Cfg 点

## 7. Meta_FCMaster / RegisterPointMeta

### 7.1 Meta_FCMaster / Meta_FCDetail

- **时机**：`FunctionCodeMasterManager.Initialize()`（LoadDB 在 InitCommand 前，`Dcs.cs:1547`）
- **用途**：仅 `Cld_FCParameter` 常数管脚的 `DataType` 判定（string*/array）（`Operation.cs:515-563`）
- **不用于**：Input/Output 顺序、默认值、Wire 属性（Wire 来自 C# `PinTypeAttribute` + TypeManage）

### 7.2 RegisterPointMeta

```csharp
m_pointMetaSnapshot[pointName] = new PointMeta {
  DESC=desc, EU=unit, MinAD=minAD, MaxAD=maxAD
};
```

(`Dcs.cs:4674-4677`)

- 调用点：InitPoint 每点注册（`Dpu.cs:1484-1485`）
- 用途：HTTP API `GetPointMetaSnapshot`；**不影响** RTD 运行时逻辑
- LoadDB 开始时随 `InvalidatePointBufferFsidCache` 清空（`Dcs.cs:4722`）

## 8. Command 两参构造 vs LoadDB 五参构造

| 构造器 | LoadDB 是否使用 | 行为 |
|--------|----------------|------|
| `(Name, FCName, Rtd, Dpu)` | 否 | 仅 `Rtd.New` 块，不建 Wire |
| `(Name, FCName, Sid)` | 反序列化 | 恢复 SID |
| `(Name, FCName, Rtd, Dpu, Operation)` | **是** | New 块 + 遍历 FC 反射 Pin + 建 Wire/sync 表 + 写默认值 |

`AddWire(...)` 系列（`Command.cs:710+`）用于运行时手工接线，**不在** LoadDB 路径调用。

## 9. FirstRun / RefreshVersion

- **FirstRun**：每 DPU 顺序调用 `commands[i].FirstRun()`（`Dpu.cs:1074-1086`；`Dcs.cs:2369-2377`）
- **RefreshVersion**：重连 DB，读 `Prj_Controller.Version`→`m_versionList`，`Prj_Project[0].VarSystemVersion`（`Dcs.cs:5230-5248`）
- **RefreshDocVersion**：读 `Prj_Document.changed`→`DocToVersionsInDb`（`Dcs.cs:5358-5377`）

## 10. 存疑汇总

| 项 | 原因 |
|----|------|
| 全表无 ORDER BY 顺序 | Jet 物理序未文档化（新系统已按自然序对齐并实证 c0 按位一致） |
| InitCommand Task 无 WaitAll | 可能与 FirstRun 竞态（对账时用 DeterministicLoad 规避） |
| Dictionary 枚举 Command 顺序 | .NET 4.7.2 未保证插入序 |
| `ForceValue`/报警限/`Negate`/`Visible` | 解析或未用 |
| `int`/`float` DataType | 静默跳过 |
| Parameter `DataType` 变量复用 | Meta 未命中时类型可能污染（粘性默认） |
