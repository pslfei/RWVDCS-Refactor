# RWVDCS 操作手册

> 面向调试工程师与教练员站开发的使用说明。部署与故障排查见《部署运维》。

## 1. 启动方式速查

```powershell
# Web 管理台模式（推荐）：空载启动，从界面装载工程
rwvdcs.exe --web 8090

# Web 管理台模式：启动即装载工程并开始连续运行
rwvdcs.exe "D:\项目\睿渥\VDCS(RuiWo)--260615.mdb" --web 8090 --start

# 常用可选参数
#   --data <目录>    数据目录（工况/快照/版本档案/历史站），默认 ./rwvdcs-data
#   --arena <目录>   Arena 使用 MMF 后备文件（默认纯内存）
#   --no-history     关闭内嵌历史站
rwvdcs.exe --web 8090 --data D:\rwvdcs-data

# 经典 CLI 模式（对账/脚本用，与 --web 互斥）
rwvdcs.exe <工程.mdb> --steps 100 --dump out.txt
rwvdcs.exe <工程.mdb> --repl
```

启动后浏览器打开 `http://localhost:8090`。

## 2. Web 管理台

左侧导航：**总览 / 点块浏览 / 工况快照 / 在线下装 / 版本档案 / 运行日志**。
顶栏常驻：工程名、版本号、指纹、运行状态徽章、开始/暂停/单步/停止按钮。

### 2.1 总览（#/dashboard）

- **装载工程**：输入 mdb 路径 → 点「装载」。装载期间系统不可用（约 10 s），完成后顶栏刷新。
- 运行控制、DPU 统计卡片、进程监控（堆内存/工作集/GC 暂停占比/线程数）。
- DPU 表格：每 DPU 的状态、周期、块数、周期统计（当前/均值/P99/超限次数）。
  - 单独设置某 DPU 周期：行内周期输入框 → 回车。
  - 统一设置全部 DPU：表格上方「统一周期」输入框。

### 2.2 点块浏览（#/browse）

三个标签页：**功能块 / 点 / 收藏夹**。

- 搜索：名称子串匹配；功能块页可按功能码类型过滤（如 `NOT`、`PID`）；点页可按类型（LA/LD/LP/LP32）过滤。
- 每行星标（★）加入/移出收藏夹；收藏持久化在浏览器本地。
- 点击行进入 **PointInfo** 详情。

### 2.3 PointInfo（#/pointinfo）

选中功能块时分 tab 展示：

| Tab | 内容 | 可操作 |
|---|---|---|
| 输入管脚 | 管脚名、连线来源、当前值、强制状态 | 强制开/关+强制值；交叉引用跳转（来源输出管脚） |
| 输出管脚 | 管脚名、输出点、当前值、使用处数量 | 强制开/关+强制值；交叉引用列出全部消费者并跳转 |
| 参数（规格数） | 装配参数当前值 | 直接修改（立即生效） |
| 内部变量 | 块私有状态字段 | 直接修改（调试用，谨慎） |

选中点时展示点的全部子字段（buffer/强制/品质等），支持写值与强制。
交叉引用弹窗中点击任意条目跳转到对应块/点的 PointInfo——这是排查逻辑传递的主要路径。

### 2.4 工况快照（#/store）

- **工况**（含工程）：保存 ~370 MB / 7-8 s；加载即完整恢复"当时的工程+全部状态"，
  加载后运行态保持加载前的状态（运行中加载完自动恢复运行）。
- **快照**（仅数据）：保存 ~27 MB / 1-2 s。指纹与当前工程一致 ⇒ 秒级整段回放；
  不一致 ⇒ 自动进入兼容转换（点按名恢复、块按名转换、已删块跳过），完成后返回转换统计。
- 表格中指纹列高亮表示与当前工程不匹配（仍可加载，走兼容路径）。

### 2.5 在线下装（#/download）

工程库逻辑修改后，不重启、不丢状态地切换到新工程：

1. 输入新 mdb 路径 → **预检**：差异报告（点/块增删改、接线、参数变更逐条列出，破坏性变更红标）。
   若预检报"致命引用问题"（如管脚引用了被删掉的块），提交按钮禁用——先回数据库修正。
2. 勾选「下装前自动备份工况」（默认开）→ **提交下装**。
3. 提交流程全自动：备份 → 旁路重建 → 构建验证 → 周期边界状态迁移 → 原子切换 → 恢复运行态。
   完成后显示迁移统计（点/块保留、新增、删除、字段转移数、强制携带数）。
4. 下装后版本号 +1，可在版本档案页查看演化链。

规则提示：
- 删除的块/点：状态丢弃（计入统计）；新增的块/点：从初值开始；
- 接线变更：按新接线重新绑定，原点值保留；
- 参数变更：新参数生效（状态迁移不覆盖装配常量）；
- 运行态保留：下装前 Running → 完成后自动恢复运行；Paused → 保持暂停可单步。

### 2.6 版本档案与日志

- **版本档案**（#/versions）：每次装载/下装/工况加载登记一条（版本号、指纹、来源、时间、mdb 路径）。
- **运行日志**（#/logs）：SSE 实时流 + 级别过滤 + 自动滚动；来源分类（工程/运行/工况/快照/下装/热更/Web）。

## 3. rwvdcs-cli（教练员站/脚本接口）

`src/Tools/RWVDCS.Tools.ApiClient` 构建产物 `rwvdcs-cli.exe`。默认连 `http://localhost:8080`，
用 `--url http://host:port` 指定。所有子命令均为 REST 的薄封装，教练员站可直接照抄 HTTP 调用。

```text
rwvdcs-cli [--url http://localhost:8090] <命令>

  status                         系统状态（工程/运行态/监控）
  dpus                           DPU 列表与周期统计
  load <工程.mdb>                装载工程
  start | pause | stop           连续运行 / 暂停 / 停止
  step [n]                       暂停态单步 n 周期（默认 1）
  cycle <秒> [DPU名]             设置周期（省略 DPU 名 = 全部）

  read <名字...>                 读点/管脚/参数（支持 DPU$、NAME.member 语法）
  write <名字=值...>             写值
  force <名字> on <值> | off     强制 / 解除强制
  watch <名字...> [-i 毫秒]      轮询监视

  cond list|save|load|del        工况管理（save/load/del 带名字）
  snap list|save|load|del        快照管理（同上）

  download prepare <新.mdb>      下装预检（差异报告 + planId + errors）
  download commit <planId>       提交下装
  versions                       工程版本档案

  logs [n] | logs follow         最近日志 / SSE 实时跟随
```

名字解析规则（read/write/force/watch 通用）：
1. 整名直接命中（点名可含 `$`、`.`）；
2. `DPU名$rest` 前缀限定；
3. `名字.成员` 拆分：点的子字段（`.forced`/`.quality`/`.buffer`…）或块管脚/字段（`块名.OUT`）。

## 4. REST API 速查（教练员站集成）

Base：`http://host:port/api`。全部 JSON；错误统一 `{"error":"..."}`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/status` | 工程/运行/监控总览 |
| POST | `/project/load` | `{mdbPath}` 装载工程 |
| POST | `/run/start` `/run/pause` `/run/stop` | 运行控制 |
| POST | `/run/step` | `{cycles}` 单步 |
| GET | `/dpus` | DPU 列表+周期统计 |
| PUT | `/dpus/cycle` | `{seconds}` 统一设周期 |
| PUT | `/dpus/{name}/cycle` | `{seconds}` 单独设周期 |
| GET | `/points?dpu=&q=&kind=&page=` | 点分页检索 |
| GET | `/blocks?dpu=&q=&fc=&page=` | 块分页检索 |
| GET | `/point/{name}` | 点详情（全子字段） |
| PUT | `/point/{name}/value` | `{value}` 写值 |
| PUT | `/point/{name}/force` | `{forced,value}` 强制 |
| GET | `/block/{dpu}/{name}` | 块详情（管脚/参数/内部变量） |
| PUT | `/block/{dpu}/{name}/pin/force` | `{pin,forced,value}` 管脚强制 |
| PUT | `/block/{dpu}/{name}/field` | `{field,value}` 参数/内部变量写 |
| POST | `/values/read` | `{names[]}` 批量读 |
| POST | `/values/write` | `{items[{name,value}]}` 批量写 |
| POST | `/values/describe` | `{names[]}` 批量定型（类型/可写性） |
| GET | `/xref/{point}` | 交叉引用（生产者/消费者） |
| GET/POST | `/store/conditions[/{name}/load]` | 工况列表/保存/加载 |
| DELETE | `/store/conditions/{name}` | 删除工况 |
| GET/POST/DELETE | `/store/snapshots...` | 快照（同工况） |
| POST | `/download/prepare` | `{mdbPath}` → 差异+planId+errors |
| POST | `/download/commit` | `{planId,backup}` → 迁移统计 |
| POST | `/hotload` | `{targets[]}` 功能码热更 |
| GET | `/project/versions` | 版本档案 |
| GET | `/logs?max=` | 最近日志 |
| GET | `/logs/stream` | SSE 实时日志 |

## 5. Remoting 兼容适配器（老客户端过渡）

老 HMI/IOMAP/Alarm 无需改动，把原先指向老 Simulator 的地址指向适配器即可：

```powershell
# Host 与适配器必须在同一台 Windows 机器上；先启动 Host，再启动适配器
rwvdcs-remoting-adapter.exe --port 8000 --api http://localhost:8090 --transport pipe
```

- 老客户端连接 `tcp://<适配器机器>:8000/Communication`（TCP + IPC 双通道，BinaryFormatter）。
- 默认 `pipe` 模式中，订阅、批量读写和变化通知使用本机固定二进制命名管道，不经过 HTTP/JSON；名称仅在订阅或 Runtime 换代时解析。
- 已支持：Attach/Detach、订阅/退订、单点与批量读写、强制、运行控制（RunDCS/PauseDCS/SingleStepDCS）、
  块详情（GetBlockDetails）、点检索（SearchPointDetail）、工况保存/加载（SaveDCS/LoadFile）、
  数据变化回调（InformDataChange，由 Host 扫描订阅并集并主动增量推送）。
- Host Runtime 重载会按名自动重绑定；Host 重启后 Edge 会重建会话并按原顺序重放订阅，老客户端看到的 Handle 保持不变。
- `--transport rest` 仅用于故障时显式回退；管道失败不会静默降级为 REST，防止性能问题被掩盖。
- 适配器会对每批订阅立即打印耗时；写值为避免高频控制台 I/O，按 1 秒窗口汇总打印。示例：

```text
[性能] 订阅 transport=pipe client=#1 requested=200 success=200 failed=0 elapsed=5.326 ms avg=26.630 us/item
[性能] 写值 1s汇总 transport=pipe calls=800 items=160000 success=160000 failed=0 errors=0 elapsedSum=221.400 ms avg=0.277 ms/call avg=1.384 us/item
```

`elapsedSum` 是该 1 秒窗口内所有写调用耗时之和；`errors` 是管道/HTTP 调用级异常数，`failed` 是点级写入失败数。

Pipe 订阅还会打印两行 IPC 分段耗时：

```text
[IPC性能] Send op=SubscribeBatch payload=483.5 KB lockWait=0.003 ms connect=0.001 ms write=3.024 ms host+read=3.066 ms total=6.094 ms
[IPC性能] Subscribe count=23171 payload=483.5 KB encode=2.034 ms send=6.094 ms decode=0.331 ms total=8.459 ms
```

- `lockWait`：等待请求管道串行锁；过大说明有其他读写/重连占用管道；
- `connect`：确保请求管道已连接；正常稳态应接近 0，约 3000 ms 表示连接超时；
- `write`：向命名管道写入帧；
- `host+read`：Host 解码、名称绑定、生成响应并读回 Edge；
- `encode/decode`：Edge 请求编码和响应解码；
- 外层`[性能] 订阅 elapsed`还包括 Edge 外部 Handle 分配、字典更新和 Remoting 方法映射。
- 不支持（老 IEdit 编辑面等）：调用返回默认值并记日志，不抛异常。
- 注意：加载大工况（数百 MB）耗时可达 10 s 量级，老客户端若配置了较短的 Remoting 超时需调大。

回归测试客户端：

```powershell
rwvdcs-legacy-client.exe --server tcp://localhost:8000/Communication --subscribe 名字1 名字2 --watch 10
rwvdcs-legacy-client.exe --block DPU1001/1001$1$DCON5 --pointdetail 1LAB20CP101XQ01
rwvdcs-legacy-client.exe --savecond 测试工况 --loadcond 测试工况
```

## 6. REPL（经典 CLI 模式）

`rwvdcs.exe <mdb> --repl`：`s [n]` 单步、`run/pause` 连跑、`p <点名>` 读点、`w <点名> <值>` 写点、
`force/unforce`、`save/load <目录>` 工况、`hotload <FC名>` 热更、`stats` 周期统计、`hist` 历史站状态、
`dump <文件>` 全点导出、`q` 退出。
